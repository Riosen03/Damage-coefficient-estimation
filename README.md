# 게임 스탯-데미지 상관관계 및 회귀 분석

독자적으로 수집한 인게임 수치 데이터를 바탕으로 주요 스탯이 데미지에 미치는 영향을 통계적으로 분석하고, 다중 선형 회귀 및 피처 셀렉션을 통해 데미지 공식을 역추적하는 데이터 분석 프로젝트입니다.

## 프로젝트 목적
본 분석은 다음 두 가지 핵심 목표를 달성하기 위해 진행되었습니다.
1. **데미지 공식(계수) 역추적** : 게임 내 설계된 데미지 수식의 구조를 파악하고, 각 **스탯(지능, 특화, 무기 공격력, 총 공격력)에 따른 변화 계수** 도출.
2. **데미지 편차(난수) 검증** : 예측 모델을 활용해 실제 타격 데이터에 포함된 **데미지 편차(최소~최대 데미지 비율)의 범위와 분포** 파악.

## 분석 환경 및 기술 스택
* Environment : Jupyter Notebook
* Data Manipulation : `pandas`, `numpy`, `sqlite3`
* Statistical Analysis & ML : `statsmodels` (OLS), `scikit-learn` (LassoCV, StandardScaler, train_test_split)
* Visualization : `matplotlib`, `seaborn`

## 분석 파이프라인 및 핵심 방법론

### 1. 데이터 로드 및 분할
* `sqlite3`를 사용하여 DB 파일로부터 Raw Data 로드
* Overfitting 방지 및 모델 검증을 위해 데이터를 Train Set과 Test Set으로 8:2 분할

### 2. 다중공선성 진단 및 피처 셀렉션 (Feature Selection)
수집된 4가지 변수 중 타겟 예측에 유의미한 독립변수를 선별하기 위해 통계적 검증을 수행
* OLS 회귀 및 히트맵(Heatmap) : 스탯 간의 상관관계를 시각화하고 OLS 회귀 결과를 분석한 결과, '지능'과 '무기 공격력'이 종속적으로 변화하며 높은 p-value를 가짐을 확인.
* LassoCV : 정규화(Regularization) 기법인 라쏘 회귀를 통해 계수(Coefficient)를 축소시키며 확실한 Predictor를 선별. 그 결과, 예측에 부적합한 지능과 무기 공격력을 모델에서 최종적으로 배제.

### 3. Log 변환을 통한 공식 선형화 (Data Transformation)
* 문제 정의 : 일반적인 게임의 데미지 공식은 합연산이 아닌 **'곱연산(데미지 = 기본값 × (1+계수))'** 구조. 따라서 이를 일반적인 선형 회귀에 그대로 적합시키면 오차가 발생.
* 해결 방법 : 독립변수와 종속변수 모두에 **Log 변환(`np.log`)**을 적용하여 곱연산 수식을 합연산 수식으로 변환하는 피처 엔지니어링을 수행. 이를 통해 선형 회귀 모델의 설명력($R^2$)을 극대화.

### 4. 이상치 제거 (Outlier Detection) 및 재학습
* 초기 분석 과정에서 잔차 범위를 크게 벗어나는 이상치(Outlier) 데이터를 식별.
* 해당 데이터를 클렌징한 후 데이터 분할 및 Log 변환 ➔ 적합 과정을 재수행하여 분석의 신뢰도 상승.

### 5. 잔차(Residual) 분석을 통한 데미지 난수 폭 증명
* 예측 수행 : Test 데이터셋을 Log 변환된 회귀 모델에 입력하여 데미지를 예측.
* 잔차 역변환 : 로그 스케일의 잔차(실제 데미지 - 예측 데미지)에 지수 함수(np.exp)를 취해 실제 데미지 비율(%)로 일괄 역변환.
* 결과 도출 : 수학적, 시각적(산점도 및 분포도) 분석을 통해 게임 내에 존재하는 최소-최대 데미지 난수 편차의 허용 범위를 성공적으로 특정.
